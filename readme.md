# Lesson 1: Fundamentals of UI/UX

## 📖 Overview
In this lesson, we will explore the core principles of user interface (UI) and user experience (UX) design. Understanding these basics is essential for building effective websites.

## 🎯 Learning Objectives
* Define the difference between UI and UX.
* Identify the 5 key principles of visual hierarchy.
* Analyze a real-world app interface for usability.

## 📺 Required Media

## 📝 Key Concepts

| Term | Definition |
| :--- | :--- |
| **Typography** | The art of arranging type to make language visible. |
| **Color Theory** | Practical guidance for color mixing and visual effects. |
| **Wireframe** | A low-fidelity visual guide that represents the framework of a website. |

---

## 🛠 Activity: Wireframe Practice
> **Task:** Draw a simple wireframe for a login page.
> **Constraint:** Use only black and white colors.
